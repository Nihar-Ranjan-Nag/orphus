# Orpheus Financial — Emerald Editorial React Redesign

A complete React/Vite/TypeScript redesign of the supplied **Web2** project.

## Preserved from Web2
- All original content and data
- Home, Services, About, Blog, Blog Article, Contact and 404 routes
- Forms, FAQ, testimonials, services, banking partners, stats, process, map and WhatsApp features
- Smooth scrolling and animations
- Local brand/banking assets

## Redesigned
- Deep emerald + ivory + restrained gold palette inspired by the supplied reference
- Editorial serif headings
- Thin-border cards with quieter shadows
- Premium dark-green navigation/hero/footer surfaces
- Better keyboard focus styling
- Developer-only Design Inspector removed from the production UI

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
